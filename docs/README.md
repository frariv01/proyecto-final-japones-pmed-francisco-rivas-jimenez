# 🇯🇵 Curso de Japonés Básico

Bienvenido al curso de **Japonés Básico**.  
Este material está pensado para estudiantes principiantes que desean aprender expresiones cotidianas, vocabulario esencial y estructuras básicas del japonés.

## 📚 Contenido del curso

### 1. Conversaciones cotidianas
- Saludos y despedidas
- Presentaciones personales
- Compras y tiendas
- Actividades prácticas
- Role-play y creación de diálogos

Material HTML con:
- Tablas de vocabulario
- Diálogos guiados
- Preguntas de opción múltiple
- Retroalimentación automática

---

### 2. Partículas gramaticales del japonés
Repaso gramatical de:
- は (wa)
- が (ga)
- を (o)
- に (ni)
- で (de)
- の (no)
- と (to)
- も (mo)
- から / まで

Incluye ejemplos y ejercicios de traducción.

---

### 3. Narrativa: Un viaje a Japón
Aventura interactiva creada en HTML/Twine donde el estudiante:
- Toma decisiones
- Lee frases sencillas
- Aprende vocabulario contextual
- Practica comprensión

---

### 4. Novela visual: Misterio en Kioto
Aventura interactiva creada en Ren'Py donde el estudiante:
- Toma decisiones
- Lee frases sencillas
- Aprende vocabulario contextual
- Practica comprensión

---

# 🎯 Objetivos del curso

Al finalizar este curso podrás:

- Saludar y presentarte en japonés
- Entender conversaciones básicas
- Utilizar partículas esenciales
- Leer frases simples
- Participar en diálogos cotidianos
- Comprender vocabulario frecuente
