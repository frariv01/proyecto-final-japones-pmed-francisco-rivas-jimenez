Conclusiones

Un curso de japonés básico en GitHub

  • Los estándares abiertos (Markdown) garantizan portabilidad y reutilización en cualquier LMS
  • Las narrativas interactivas (Twine + RenPy) aumentan la motivación y el aprendizaje contextual
  • GitHub como repositorio ofrece control de versiones, historial y publicación web gratuita e inmediata
  • Pandoc demuestra que un único fuente Markdown genera múltiples formatos de salida sin esfuerzo adicional
  • La combinación de formatos responde a distintos estilos de aprendizaje: visual, lector, jugador, oyente
